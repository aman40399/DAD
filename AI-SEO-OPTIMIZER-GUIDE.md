## 📊 SEO Score Calculation

```
Total Checks: 7
- Title Length (pass/warning/fail)
- Excerpt Length (pass/warning/fail)
- Content Length (pass/warning/fail)
- Headings (pass/warning)
- Internal Links (pass/warning/fail)
- External Links (pass/warning)
- Tags (pass/warning)

Score Formula:
- Pass = 100% weight
- Warning = 50% weight
- Fail = 0% weight

Example:
- 5 Pass + 2 Warning = (5 + 1) / 7 = 85.7 ≈ 86/100
```

## 🔧 Technical Implementation

### **Components:**
- **File:** `/components/AISEOOptimizer.tsx`
- **Type:** Client component ('use client')
- **State Management:** useState for modal, analysis, optimization progress

### **API Integration:**
Uses `/api/ai/generate` endpoint with NVIDIA API:
- **Title optimization:** `action: 'headline'`
- **Excerpt generation:** `action: 'excerpt'`
- **Focus keyword:** `action: 'generate'`
- **Content enhancement:** `action: 'enhance'`
- **Tags generation:** `action: 'tags'`

### **Props:**
```typescript
interface AISEOOptimizerProps {
  title: string
  content: string
  excerpt: string
  category: string
  tags: string[]
  onOptimize: (optimized: {
    title: string
    excerpt: string
    content: string
    tags: string[]
    focusKeyword: string
  }) => void
}
```

### **Integration:**
```typescript
<AISEOOptimizer
  title={formData.title}
  content={formData.content}
  excerpt={formData.excerpt}
  category={formData.category}
  tags={formData.tags.split(',')}
  onOptimize={(optimized) => {
    setFormData(prev => ({
      ...prev,
      title: optimized.title,
      excerpt: optimized.excerpt,
      content: optimized.content,
      tags: optimized.tags.join(', ')
    }))
  }}
/>
```
